# Returns and Refunds Policy (Aurora Marketplace)

*Synthetic knowledge base for a fictional marketplace, written for the ChurnSight demo.*

## Right of withdrawal (any reason)
Following Brazil's Consumer Defense Code (CDC, Art. 49), customers may return any item bought online within **7 days of receiving it**, for any reason. Return shipping is free and the refund includes the original shipping cost.

## Defective items
Under CDC Art. 26, customers can claim for defects within **30 days** for non-durable goods and **90 days** for durable goods. Return shipping is free. The customer chooses a **replacement** or a **full refund**.

## Refund timing
Refunds are issued to the original payment method within **10 business days** after the returned item reaches the seller, or immediately when no return is required (see *Damaged or Defective Items*).

## Exchanges
Exchanges for a different size or colour are handled as a return plus a new order, subject to stock.
