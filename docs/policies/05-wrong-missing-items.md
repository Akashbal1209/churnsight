# Wrong or Missing Items Policy (Aurora Marketplace)

*Synthetic knowledge base for a fictional marketplace, written for the ChurnSight demo.*

## Missing items or partial deliveries
Orders with several items may ship in separate parcels. Check tracking for each parcel first. If an item is confirmed missing, the seller ships it within **5 business days**, or the customer receives a **partial refund** for that item plus the proportional shipping cost.

## Wrong item, colour, size or model
If the customer received something different from the listing, the seller arranges **free return shipping** and sends the correct item, or the customer receives a **full refund**. The customer chooses.

## Product different from the description
If the product does not match the listing (material, size, specifications), treat it as a wrong item. The listing is flagged for review by the Seller Quality team.
